## 2. 수용한 트레이드오프

선택 시 의식적으로 받아들인 위험. 나중에 "왜 이렇게 했냐"에 대한 답이다.

| 결정 | 받아들인 위험 | 완화 |
| --- | --- | --- |
| D32 자동 Viewer | 테일넷에 공유 노드나 외부 사용자가 섞이면 그들도 조회 가능 | Tailscale ACL로 Beacon 노드 접근 자체를 제한 |
| D33 만료 없음 | 테일넷에서 제거된 사용자의 패스키가 외부에서 계속 유효 | 사용자 제거 시 Beacon에서도 비활성화하는 것을 운영 절차로 둠 |
| D34 외부 Owner 작업 | 외부 세션이 탈취되면 전체 권한 노출 | 패스키는 피싱 저항성이 있음. Owner 작업은 전부 감사 로그 기록 |
